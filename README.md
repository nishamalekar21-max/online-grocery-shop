# 🛒 Online Grocery Shop

A web-based online grocery shopping system that allows users to browse
products, add items to a cart, and manage their shopping experience.

## ✨ Features

- 🛍️ Browse grocery products
- 🔎 Product search
- 🛒 Add to cart
- 👤 User management
- 📦 Order management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## 🚀 How to Run

1. Install XAMPP
2. Put the project inside htdocs
3. Start Apache and MySQL
4. Open the project through localhost
